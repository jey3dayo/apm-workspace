# Claude Code のモデル運用

このルールは Claude Code の対話メインセッションに適用する。

## 通常運用

通常は Sonnet メインと Opus advisor を使う。
設計だけに Opus が必要なら `/model opusplan` と Plan Mode を使う。
設計後も継続して高度な判断が必要なら `/model opus` を使い、その作業を終えたら `/model sonnet` に戻す。
モデル切り替えコマンドはユーザーが実行する。

## Advisor に相談する条件

Sonnet メインで advisor が利用できる場合、次の時点で相談する。

- 複数案の比較や責務・互換性の判断を伴う設計を確定する前。
- 非軽微な変更の検証を終え、完了を報告する前。
- 同じエラーが2回続いた時点で、3回目を試す前。

同じ判断点への相談は1回とし、新しい証拠や前提変更がある場合に再相談する。
事実照会、文章修正、機械的な軽微修正では定例の相談を省略する。
Opus で検討済みの同じ設計論点への重複相談も省略する。
Advisor の助言は実ファイルと検証結果に照らして採否を決める。
相談できなかった場合は、未実施であることを報告する。
Advisor は既定の full gate・独立レビュー・失敗時の停止条件を代替しない。
