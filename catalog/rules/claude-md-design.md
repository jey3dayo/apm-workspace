# CLAUDE.md Design Principles

## 目的

global 共有ガイド（`catalog/AGENTS.md`、配布先は `~/.claude/CLAUDE.md` と `~/.codex/AGENTS.md`）を汎用的かつ保守しやすく保つための設計原則。各 repo 固有の AGENTS.md / CLAUDE.md には適用しない

## 設計原則

### 1. 責任の分離

- CLAUDE.md: 汎用的なガイドラインのみ
- スキル: 機能固有の詳細（コマンド、ワークフロー等）
- steering: プロジェクト固有のルール

### 2. 削除すべき情報

- スキル固有の詳細（コマンド一覧、ワークフロー等）
  - 理由: スキル自体が詳細を持っているため重複
- 動的に変わる情報（スキル一覧・件数など）
  - 理由: 最新性を保つのが困難、使用時にスキルを参照すべき
- スキルが正本を持つツール/フレームワークの詳細（使い方、コマンド一覧）
  - 理由: スキルまたはsteeringに委譲する。どのツールを選ぶかの選択規則（コマンド選択表）は汎用ルールとして global に置いてよい

### 3. 維持すべき情報

- プロジェクト固有ルールの置き場（各 repo の AGENTS.md / steering）への案内
  - 理由: 固有ルールを global に写さないため
- 汎用的な開発ルール
  - 理由: すべてのプロジェクトに適用可能
- 言語設定
  - 理由: ユーザー体験の基本設定

### 4. 汎用的なルールの特徴

- プロジェクト/ツールに依存しない
- 開発の基本姿勢を示す
- 自律性と効率性を促進
