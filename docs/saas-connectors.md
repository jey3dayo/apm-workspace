# SaaS Connectors

SaaS への接続手段の選び方をまとめています。接続状況は環境や時点で変わるため一覧は固定せず、作業時に利用可能なツールとアプリ側の接続設定を確認します。採用や撤去の意思決定ログは [`docs/package-decisions.md`](package-decisions.md) にあります。

## 配置優先度

接続手段は次の優先順で選びます。上位の手段が使えるときは、下位の手段と二重に管理しません。

1. アプリ側プラグイン / コネクタ: claude.ai の managed MCP コネクタや ChatGPT アプリのプラグインです。認証、トークン更新、ツール定義の保守をアプリ側に集約できます。
2. `apm.yml`（external skill / MCP）: アプリ側コネクタがない場合、または headless 環境や CLI で常用する必要がある場合に限ります。
3. `catalog/.apm/skills`（自作スキル）: 上記では対応できない固有のワークフローに限ります。

コネクタと役割が重ならないスキルは撤去の対象にしません。たとえば、`slack-app-management` は Slack アプリを管理するためのスキルであり、SlackDB コネクタとは役割が異なります。

どちらか一方のアプリにしかプラグインがない場合は、APM で管理して両方に配って構いません。両方のアプリにコネクタがそろったら撤去を検討します。
