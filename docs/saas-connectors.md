# SaaS Connectors

SaaS への接続手段の選び方を説明します。接続状況は環境や時点で変わるため一覧は固定せず、作業時に利用可能なツールとアプリ側の接続設定を確認します。
採用・撤去の意思決定ログは `docs/package-decisions.md` に記録します。

## 配置優先度

SaaS への接続手段は次の優先順で選びます。上位の手段が使える場合は、下位で二重管理しません。

1. アプリ側プラグイン / コネクタ: claude.ai の managed MCP コネクタや ChatGPT アプリのプラグインです。認証・トークン更新・ツール定義のメンテナンスがアプリ側に集約されます。
2. `apm.yml`（external skill / MCP）: アプリ側コネクタがない場合、または headless / CLI で常用する必要がある場合に限ります。
3. `catalog/.apm/skills`（自作スキル）: 上記で対応できない固有のワークフローに限ります。

コネクタと役割が重ならないスキル（例: `slack-app-management` は Slack アプリ管理用であり、SlackDB コネクタとは別役割）は撤去対象にしません。

片方のアプリにしかプラグインがない場合は、APM 管理にして両方へ配って構いません。両方にコネクタがそろったら撤去を検討します。
